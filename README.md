# Function Analyzer

**Автор:** Сермягин Николай Михайлович, группа M3119

## Описание
Плагин для Visual Studio Code анализирует C++-функции в выделенном
фрагменте кода (или во всём файле) и находит слишком длинные или слишком
глубоко вложенные.

## Возможности
- Подсчёт длины каждой функции в строках и максимальной вложенности `{}`.
- Анализ выделенного фрагмента или всего файла, если выделения нет.
- Подчёркивание проблемных функций в редакторе с пояснением.
- Вывод результатов в панель Output и итогового уведомления.
- Настраиваемые пороги: `functionAnalyzer.maxLength` (по умолчанию 30) и
  `functionAnalyzer.maxDepth` (по умолчанию 3).
- Запуск командой **Analyze C++ Functions** из палитры команд,
  контекстного меню или по `Ctrl+Alt+F`.
