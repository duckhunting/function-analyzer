
# Техническое задание: плагин «Function Analyzer»

1. **Назначение.** Анализ C++-функций: вычисление длины и максимальной
   вложенности блоков `{}` для выявления функций, которые стоит разбить.
2. **Платформа.** Visual Studio Code. Плагин написан на TypeScript,
   анализируемый код C++.
3. **Вызов.** Команда «Analyze C++ Functions»: палитра команд
   (`Cmd+Shift+P`), контекстное меню в `.cpp`-файлах, `Ctrl+Alt+F`.
4. **Входные данные.** Выделенный фрагмент кода, а если выделения нет,
   весь файл.
5. **Обработка.** Для каждой функции определяются имя, длина в строках и
   максимальная вложенность `{}`.
6. **Пороги.** Длина больше 30 строк или вложенность больше 3 считаются
   нарушением. Значения настраиваются в настройках VS Code
   (`functionAnalyzer.maxLength`, `functionAnalyzer.maxDepth`).
7. **Вывод.** Панель Output со списком функций, подчёркивание проблемных
   функций в редакторе, итоговое уведомление.
8. **Поддерживаемые стили.** Скобка `{` в конце строки и на отдельной строке.
9. **Ограничения.** Разбор эвристический (регулярные выражения и стек
   скобок). Не обрабатываются блочные комментарии `/* */`, лямбды и
   макросы с `{}`.
