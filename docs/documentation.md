# Function Analyzer: документация

## 1. Общее описание решения
Плагин для VS Code анализирует C++-функции в выделенном фрагменте кода
(или во всём файле) и находит слишком длинные или слишком глубоко
вложенные. Для каждой функции вычисляется длина в строках и максимальная
вложенность `{}`. Пороги настраиваются (`functionAnalyzer.maxLength`,
`functionAnalyzer.maxDepth`). Результаты выводятся в панель Output,
подчёркиваются в редакторе и сообщаются уведомлением.

Модули: `src/analyzer.ts` (разбор и оценка), `src/extension.ts`
(интеграция с VS Code).

## 2. Описание функций

### findFunctions(lines, firstLine = 0)
Находит функции в списке строк и считает их длину и вложенность.
Используется стек скобок: метка `1` для скобки тела функции, `0` для
остальных.

Пример вызова:
```ts
const res = findFunctions(['int Sum(int a, int b) {', '  return a + b;', '}']);
// res[0] = { name: 'Sum', startLine: 0, endLine: 2, length: 3, maxDepth: 0 }
```

### evaluate(functions, limits)
Сравнивает каждую функцию с порогами и возвращает результат с флагами
`tooLong` и `tooDeep`.

Пример вызова:
```ts
evaluate([info], { maxLength: 30, maxDepth: 3 });
```

### clean(line)
Внутренняя функция. Заменяет строковые литералы и комментарии `//`
пробелами, сохраняя длину строки.

Пример вызова:
```ts
clean('int a = 1; // счётчик');
```

### activate(context)
Точка входа расширения. Регистрирует команду `functionAnalyzer.run`,
панель Output и коллекцию диагностик.

Пример: пользователь запускает `Cmd+Shift+P` → «Analyze C++ Functions».

### deactivate()
Вызывается VS Code при отключении расширения.
